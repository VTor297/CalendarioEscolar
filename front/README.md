# Frontend — Calendário Escolar

Aplicação React 19 com Vite.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Organização do código

- `src/App.jsx`: controla a sessão e direciona o usuário para a interface do perfil.
- `src/components/Login.jsx`: autenticação demonstrativa.
- `src/components/Coordenacao.jsx`: interface da Coordenação.
- `src/components/Professor.jsx`: interface do Professor.
- `src/components/Aluno.jsx`: interface do Aluno.
- Cada componente possui seu CSS correspondente.
- `src/assets/`: imagens e recursos importados pelo frontend.
